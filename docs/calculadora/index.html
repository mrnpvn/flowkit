Preguntas frecuentes

¿Se envían mis datos a algún sitio?

No. El cálculo se hace en tu navegador con JavaScript. No hay formulario, no hay cookies y no se envía nada a ningún servidor.

¿Qué porcentaje de automatización debo poner?

Entre el 40 % y el 60 % es un punto de partida razonable para avisos, copias y seguimientos. La decisión, la excepción y la relación con el cliente siguen siendo humanas.

¿El ahorro es dinero que aparece en la cuenta?

No necesariamente. El cálculo valora el tiempo a coste de hora. Se convierte en dinero si se factura más, se atiende mejor o se evita una contratación.
